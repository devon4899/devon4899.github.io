01 / Idea

Make the everyday entry small.

Tap Track is a native iOS nutrition counter designed around quick, direct entry. Choose a nutrient, choose an increment, and tap to build an entry before logging it.

Daily totals and longer-term history sit in the same app, so a small action can feed a useful picture of the week and month.

02 / Product decisions

A short path from a number to a record.

Make the main action obvious

A large increment control supports calorie and nutrient logging. Totals can also be edited directly.

Let the user set the context

Guided setup, configurable goals, nutrient selection, and themes personalize the tracker.

Show history at two scales

Weekly charts compare daily entries with target lines. The monthly calendar and breakdown show consistency across dates.

03 / Current build

A small, self-contained iOS app.

Built with SwiftUI, Swift Charts, and UIKit, using AppStorage and UserDefaults for local records. The project retains its original CalorieCount folder name; the app’s product name is TapTrack.

The current source and test targets compiled successfully on November 12, 2026. The gallery was captured from that build using synthetic demonstration history. This is a pre-release project, with its current GitHub showcase and development source maintained separately.
