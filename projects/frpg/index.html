01 / Idea

Give every workout a little continuity.

FRPG began as a fitness RPG tracker. Its current development version, Liftling, pairs a practical workout log with a pixel creature that grows through training.

Choose a companion, set a weekly aim, and return to a routine with targets from the last session. Progress in the gym becomes progress along the creature’s Path.

02 / Product decisions

Make the next session easy to start.

Keep training at the center

Reusable routines bring back previous-set targets. Sets, repetitions, weight, and rest timing stay close to the workout.

Reward actual training

Completed workouts contribute to XP, gear, and a Path with twelve bosses. The creature gives that progress a visible home.

Keep records useful

History, personal records, and strength charts let the user see what changed beyond the game.

04 / Current build

Native, local-first, and still in development.

Built with SwiftUI and Apple frameworks, including Charts, WidgetKit, ActivityKit, and HealthKit. The current simulator build and screenshot walkthrough passed on November 12, 2026.

This is a pre-release project. The public FRPG repository contains the earlier source snapshot and an updated gallery of Liftling. Current development code is maintained separately.
